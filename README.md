# 🎓 Oasis Infobyte Internship - Java Development

This repository contains my completed work during the **Java Development Internship** at **Oasis Infobyte (OIBSIP)**.
The repository showcases console-based Java applications built using core programming principles, Object-Oriented Programming (OOP), dynamic data structures, and robust input validation.

---

## 📖 Project Overview

The internship involved implementing practical Java projects designed to solve real-world logic problems and build modular software systems. Each task was implemented, tested, and documented with clean directory architecture and execution summaries.

---

## ✅ Tasks Completed

### 1️⃣ Task 2: Number Guessing Game

- Built a console-based game generating secret targets across configurable difficulty levels (Easy, Medium, Hard).
- Implemented real-time feedback ("Too High" / "Too Low"), attempt counters, and multi-round tracking.
- Designed an end-of-game summary report displaying target numbers, attempts taken, and final win/loss outcomes.

### 2️⃣ Task 3: ATM Interface

- Engineered a multi-class banking system simulation demonstrating Encapsulation and Data Hiding.
- Implemented secure user authentication with PIN validation and maximum retry attempts.
- Enabled deposit, withdrawal, direct account-to-account transfer capabilities, and timestamped transaction history logging.
